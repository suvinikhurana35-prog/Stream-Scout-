Stream Scout - installable app (PWA)
1. Upload this whole folder to any HTTPS host (Netlify Drop, GitHub Pages, Vercel, your own site).
2. Open the link on a phone.
   Android Chrome: tap "Install app" (or menu > Install app).
   iPhone Safari: Share > Add to Home Screen.
3. It opens full-screen like a normal app and works offline after the first visit.
To make an Android APK: paste your hosted link into pwabuilder.com.
Edit all text at the top of the script in index.html (T, ST, Q).
